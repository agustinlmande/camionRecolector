    🎯 ¿Qué es la Programación Orientada a Objetos?

    La POO es un paradigma de programación que organiza el código en objetos, que son instancias de clases.

    📦 Objetos

    Entidades que combinan datos (propiedades) y comportamientos (métodos)

    🏗️ Clases

    Plantillas o moldes para crear objetos con estructura definida

    ⚙️ Métodos

    Funciones que definen el comportamiento de los objetos

    Ejemplo Básico de Clase 
    class CamionResiduos {
    private string $matricula;
    private string $conductor;
    private float $capacidad;
    
    public function __construct(string $matricula, string $conductor) {
        $this->matricula = $matricula;
        $this->conductor = $conductor;
    }
    
    public function cargarResiduos(float $peso): bool {
        return $peso <= $this->capacidad;
    }
}

    📋 Implementación: Clase RutaResiduos

    Clase principal que representa una ruta de recolección de residuos:

    RutaResiduos.php 
    <?php
declare(strict_types=1);

class RutaResiduos {
    private int $id;
    private string $camion;
    private string $conductor;
    private string $ruta;
    private string $horario;
    private string $estado;
    
    public function __construct(
        ?int $id = null,
        string $camion = "",
        string $conductor = "",
        string $ruta = "",
        string $horario = "",
        string $estado = "pendiente"
    ) {
        $this->id = $id ?? 0;
        $this->camion = $camion;
        $this->conductor = $conductor;
        $this->ruta = $ruta;
        $this->horario = $horario;
        $this->estado = $estado;
    }
    
    // Getters
    public function getId(): int { 
        return $this->id; 
    }
    
    public function getResumen(): string {
        return "Ruta {$this->id}: {$this->ruta} - {$this->estado}";
    }
    
    public function estaActiva(): bool {
        return $this->estado === 'pendiente' || 
               $this->estado === 'en-proceso';
    }
}

    Métodos CRUD en GestorRutas 
    class GestorRutas {
    private array $rutas = [];
    
    // CREATE
    public function crearRuta(RutaResiduos $ruta): bool {
        $ruta->id = $this->generarNuevoId();
        $this->rutas[$ruta->getId()] = $ruta;
        return $this->guardarRutas();
    }
    
    // READ
    public function obtenerPorId(int $id): ?RutaResiduos {
        return $this->rutas[$id] ?? null;
    }
    
    // UPDATE
    public function actualizarRuta(RutaResiduos $ruta): bool {
        if (!isset($this->rutas[$ruta->getId()])) {
            throw new InvalidArgumentException("Ruta no encontrada");
        }
        $this->rutas[$ruta->getId()] = $ruta;
        return $this->guardarRutas();
    }
    
    // DELETE
    public function eliminarRuta(int $id): bool {
        if (!isset($this->rutas[$id])) {
            throw new InvalidArgumentException("Ruta no encontrada");
        }
        unset($this->rutas[$id]);
        return $this->guardarRutas();
    }
}
